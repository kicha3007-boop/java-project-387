# 1. TypeScript на обеих сторонах, один сервис

Статус: принято

## Контекст

Проект ведётся агентом; стек свободный, результат — один Docker-образ, слушающий `PORT`.

## Решение

- Бекенд: Node.js 22 + Fastify. Фронтенд: React + Vite. Язык обеих частей — TypeScript.
- Один процесс отдаёт и API (`/api/...`), и собранный фронтенд; маршруты фронтенда (`/book/...`,
  `/owner/...`) получают `index.html`.
- Один `package.json` в корне: без workspaces, проект маленький.

## Последствия

- Один образ и один порт, без CORS и отдельного деплоя фронтенда.
- Типы из контракта общие по смыслу для обеих сторон, агент работает в одном языке.
