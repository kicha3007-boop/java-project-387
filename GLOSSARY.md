# Glossary

Словарь проекта. Эти слова одинаково используются в интерфейсе, коде, тестах и тикетах.

| Термин | Значение | Не путать / не называть |
|---|---|---|
| **Владелец календаря** (owner) | Единственный заранее заданный профиль, который публикует типы встреч и смотрит предстоящие встречи. Входа нет. | «админ», «пользователь» |
| **Гость** (guest) | Человек, который записывается на встречу без аккаунта: оставляет имя и почту. | «клиент», «посетитель» |
| **Тип встречи** (event type) | Шаблон встречи владельца: `id`-слаг, название, описание, длительность (кратна 30 минутам). | «событие», «услуга» |
| **Каталог типов встреч** | Страница `/book` со всеми типами встреч — точка входа гостя. | «список событий» |
| **Окно записи** (booking window) | 14 календарных дней, начиная с текущей даты (UTC). За его пределами записи нет. | «период», «горизонт» |
| **Рабочие часы** | Интервал дня, в котором бывают слоты: 09:00–18:00 UTC. | |
| **Слот** (slot) | Свободный интервал длительностью типа встречи, начало на сетке 30 минут внутри рабочих часов окна записи. | «окно», «таймслот» |
| **Сетка** | Шаг 30 минут, на который выровнены начала слотов. | |
| **Бронирование / встреча** (booking) | Занятый гостем интервал выбранного типа встречи. В интерфейсе владельца — «встреча». | «заказ», «резерв» |
| **Занятость** (busy) | Интервалы всех бронирований любых типов. Слот не предлагается, если пересекается с занятостью. | |
| **Конфликт слота** | Попытка забронировать время, пересекающееся с занятостью. Ответ API `409 slot_unavailable`. | |
| **Подтверждение** | Экран после успешной записи с типом встречи, датой и временем. | |
| **Контракт** | TypeSpec-описание API в `spec/main.tsp`; OpenAPI и SDK генерируются из него. | «схема», «swagger» |
